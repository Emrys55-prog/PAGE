HEADER PICTURE
--------------
The big picture at the top of the home page is read from:

    images/header.jpg

1. Take or choose a photo (a borehole, a water kiosk, a river, the campus).
2. Rename it to header.jpg and put it in this folder.
3. Refresh the page.

Tips
- A landscape photo works best. About 1200 x 900 pixels is plenty.
- Keep the file under 500 KB so the page loads fast on a phone.
- If header.jpg is missing, the page shows header-placeholder.svg instead.
- To use a .png or .webp, change the file name in index.html on the
  line that says src="images/header.jpg".
